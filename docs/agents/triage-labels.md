# Triage labels

| Role | Local label | Meaning |
| --- | --- | --- |
| Needs triage | `needs-triage` | Evaluate the request |
| Needs information | `needs-info` | Await missing information |
| Ready for an agent | `ready-for-agent` | Acceptance criteria and dependencies are specified |
| Ready for a human | `ready-for-human` | Human implementation is required |
| Will not fix | `wontfix` | Work will not be pursued |

These default labels classify readiness, not completion or permission to execute.
Completed implementation tickets use `done` with verification evidence.
